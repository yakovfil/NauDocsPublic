Welcome to Nau Engine API Reference!
---------------------------------------------

This documentation provides detailed descriptions, parameters, and examples for numerous classes, functions, and modules available in the engine. 
For current beta release the reference focuses more on C++ scripting API, however, you can find information on numerous other entities,
even on those deeply embedded in the engine core. This should help you comprehend the internal structure of our product, understand its capabilities and limitations.
What's more, this reference may serve as a starting point of your way to improve Nau Engine.
